# webassistant-skill-sdk

SDK para crear skills de WebAssistant fuera del núcleo: tipos (`SkillContext`, `RetrievedSource`,
`SkillHandler`, `ActionHandler`, `ActionResult`), carga y validación de paquetes y la CLI
`webassistant-skill`:

```bash
webassistant-skill new mi_skill --dir ./skills
webassistant-skill validate ./skills/mi_skill
```

Guía completa: [docs/skills.md](../../docs/skills.md).
